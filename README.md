# Nuwantha Sanduka — Portfolio

Welcome to my personal portfolio website. I am Nuwantha Sanduka, a UI/UX Designer and Front-End Developer from Sri Lanka.

I designed this portfolio interface in Figma and developed it using HTML, CSS, and vanilla JavaScript. The website showcases my skills, education, professional experience, projects, and contact information.

## Features

- Responsive layout for desktop, laptop, tablet, and mobile devices
- Custom mobile hero section based on my Figma design
- Smooth hero loading and scroll-reveal animations
- Fixed responsive navigation bar
- Mobile four-square navigation menu
- About Me and education sections
- Skills and development tools showcase
- Automatically scrolling tools carousel
- Horizontally scrollable project cards
- Professional experience timeline
- Viewable and downloadable PDF CV
- Contact and social media links
- Responsive footer
- Locally stored fonts and images

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Figma
- Git and GitHub

## Run the Project Locally

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using the Live Server extension.

The website can also be opened by double-clicking the `index.html` file.

## Updating Project Links

The current project cards contain placeholder buttons. Replace them with the relevant Live Demo and GitHub repository URLs inside `index.html`.
